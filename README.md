# טוסטי הגיבור

משחק פלטפורמה תלת־ממדי בעברית לילדים. פרוסת טוסט עם גלימה עוברת שישה עולמות של אוכל, מצילה חברים שנתקעו בבועות ומנצחת בוס בסוף כל עולם.

## העולמות

| עולם | אוספים | אויבים | חבר להצלה | בוס |
|---|---|---|---|---|
| פיצה־לנד | פפרוני | זית חמוץ, עגבנייה קופצת, אננס דוקרני מתגלגל | בצלצל | פטריית הענק |
| ארץ הממתקים | סוכריות | דובון גומי, סוכריית ג'לי, תירס ממתק מעופף | קאפקייקי | מלך הסוכריות |
| המטבח הגדול | קוביות סוכר | ספוג, מזלג, מטרפה מעופפת | כוסונת | הקומקום הרותח |
| בוקר טוב | אוכמניות | בייקון, פול קפה, פתית קורנפלקס | תותית | מגדל הפנקייקים |
| הרי הגלידה | דובדבנים | ארטיק, קוביית קרח, כדור שלג | גלידונת | גביע הקרח |
| הר הצ'ילי | גרעיני תירס | צ'ילי, חלפיניו, בקבוק רוטב | אבוקדון | הרוטב הלוהט |

## שליטה

| מחשב | פעולה |
|---|---|
| W A S D / חיצים | הליכה |
| גרירה עם העכבר / Q E | סיבוב המצלמה |
| רווח (להחזיק באוויר) | קפיצה וגלישה עם הגלימה |
| X / Shift | סיבוב גלימה |
| C באוויר | נחיתת רעם |
| Esc / P | הפסקה |

בטאבלט ובטלפון: גוררים בצד שמאל כדי ללכת, בצד ימין כדי לסובב את המצלמה, ולוחצים על הכפתורים בפינה.

## הפעלה

המשחק עובד ישירות מ־GitHub Pages ואפשר להוסיף אותו למסך הבית. אחרי הכניסה הראשונה הוא עובד גם בלי אינטרנט.

## עדכון

אחרי שינוי בקבצי המשחק, מעלים את המספר ב־`VERSION` שבקובץ `sw.js` (למשל `toasty-v2`), כדי שמכשירים שהתקינו את המשחק יקבלו את הגרסה החדשה.
